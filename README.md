# 🏋️ my-fit-log-app

FITLOG is a modern workout planning web application designed to help users explore workouts, build their personal workout plan, and save their favorite exercises in one place.

## 🚀 Technologies Used

* **Next.js** – React framework for building the application
* **React** – Building reusable UI components
* **TypeScript** – Type-safe development
* **Tailwind CSS** – Styling and responsive design
* **DaisyUI** – UI components
* **Context API** – Managing workout and plan state
* **REST API** – Fetching workout and library data

## ✨ Key Features

### 1. 🏋️ Workout Library

Browse a collection of workouts covering different muscle groups and exercises. Each workout provides useful information to help users understand the exercise.

### 2. 📋 Personal Workout Plan

Users can add workouts to their personal plan and easily view the exercises they have selected.

### 3. 💾 Save Favorite Workouts

Users can save workouts for later and access their saved exercises from the Saved section.

### 4. 🔄 Dynamic Plan Management

The application uses React Context API to manage selected workouts and saved workouts dynamically across the application.

### 5. 📱 Responsive Navigation

FITLOG provides a responsive navbar with separate navigation for **Workouts** and **My Plan**, including an active navigation state that indicates the current page.
